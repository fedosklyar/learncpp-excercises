# Chapter 4: Fundamental Data Types

This directory contains the solutions to the practical questions, given throughout the chapter. Along with that the simple program for the presentation of a number according to the scientific notation was developed.

## What the Programs Demonstrate
* **Fundamental data types:** In this chapter we went beyond the simple `int` type and got to know other fundamental types, both integral and non-integral, and their specifics and peculiarities when it comes for processing them, getting the input for those types and so on.
* **Types casting:** Along with the introduction of more types the way of converting the value of one type to another and the reasons for that were reviewed.
* **Output manipulators:** With the new types come the struggles of displaying them properly. This issues are addressed by the output manipulators, which, no wonder, modify the behavior of the `std::cout` object. 
* **if-statements:** This chapter also provides a general and high-level introduction to the if-statement.
* **Scientific notation:** While relatively niche topic, I decided to write a simple program, which outputs a normal decimal number in accordance with the scientific notation, using the calculational approach. Since this approach has it's limits, the program will be revised in the upcoming chapters with the usage of `std::string` type.
